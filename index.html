TRICKY MATH

What is Tricky Math?

Tricky Math is dedicated to children (ages 8-10), but it can be a good brain training even for adults.

The user will find 25 math exercises based on logical thinking and text understanding.

If someone is preparing for the Zrinyi Ilona Math Competition, then it is the right place for learning and practicing.

What you need to know

Basic mathematical operations like addition, subtraction, multiplication, and division.

Basic knowledge a second grade student should know.

Examples: the days of the week; the months of a year; number of second in a minute;

number of hours in a day; telling the time; measurement of length, mass and of liquid, etc.

Using this application will make easier to improve skills and develop abilities.

Competition Mode

  • A 60 minutes timer is set.
  • You can see your points only after you submitted the last answer.
  • The test starts with easy exercises and continuously gets more difficult.
  • You can submit exercises without choosing an answer.
  • Scoring formula: 4*Correct - Wrong + Exercises.

    Example: 4*25 - 0 + 25 = 125 points.
